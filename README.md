# 矩阵工坊 · 构建科学发现的流水线

14 页交互式 HTML 产品演示，包含动态科研场景、真实产品截图和论文示例。

## 查看

直接用浏览器打开 `index.html`，无需安装依赖，所有图片和动画已嵌入页面。

也可以在安装 Python 3 后运行 `npm start`，访问 http://127.0.0.1:8787 。

- 使用左右方向键、空格或底部按钮翻页。
- 点击目录按钮选择页面，Home / End 跳到首尾页。
- 点击截图查看高清原图；部分页面可切换不同截图组。
- 封面动画可暂停，演示支持全屏。

## 修改与生成

需要 Node.js 18 或更高版本，无需安装第三方依赖。

```sh
npm run build
```

修改 `scripts/build.mjs` 中的文字、布局与页面顺序，然后重新生成 `index.html`。

- `assets/screenshots/`：原始产品与论文截图。
- `assets/scenes/`：科研场景配图。
- `assets/product.png`：首页产品展示。
- `assets/factory.svg`：首页流水线动画素材。
- `scripts/animate.js`：科研场景动画。

## 演示顺序

产品愿景 → 我们做什么 → AI 科研的最后一公里 → 定义研究问题 → 科研环境 → 团队协作 → 科研工具 → 持续探索 → 进度与审核 → 形成研究结论 → Lean4 验证 → 论文与成果交付 → 完整任务总结 → 机构申请。
