# 矩阵工坊 · 构建科学发现的流水线

17 页交互式 HTML 产品演示：面向数学研究的 AI 科研 Agent。

## 查看

直接用浏览器打开 `index.html`，截图已全部内嵌。也可以运行 `npm start`，然后访问 http://127.0.0.1:8787 。

标题字体（Noto Serif SC / Noto Sans SC / JetBrains Mono）从 Google Fonts 加载；离线时会回退到系统字体（宋体 / 苹方 / 微软雅黑）。

| 操作 | 按键 |
| --- | --- |
| 翻页 | ← → / 空格 / PageUp PageDown / 触屏左右滑 |
| 首页 / 末页 | Home / End |
| 目录 | G（第 4 页的条目也可以点击跳转） |
| 全屏 | F |
| 截图 | 点击放大，再点一次切换原始尺寸；部分页面有标签可切换截图 |
| 导出 PDF | 浏览器打印 → 另存为 PDF（每页一张 1440×810） |

## 修改与生成

需要 Node.js 18 或更高版本，无需第三方依赖。

```sh
npm run build
```

- `scripts/build.mjs`：全部页面内容与页序。每一页对应一个 `add(...)` 调用。
- `src/deck.css`：设计系统，包括颜色 token、字体与各页组件样式。
- `src/deck.js`：翻页、目录、截图画廊与放大等交互；`[data-tl]` 时间轴按 `data-at` / `data-off`（毫秒）驱动页面内的分步动画。
- `assets/screenshots/`：产品与论文截图；`assets/product.png`：封面产品图。
- `assets/scenes/`、`assets/factory.svg`：旧版配图，新版未使用，保留备用。

设计说明：使用暖白纸色底与墨黑衬线标题，取产品主色荧光绿作为唯一强调色；封面与结尾使用深色。产品截图统一放进深色窗口框，与产品界面保持一致。
